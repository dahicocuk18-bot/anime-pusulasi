# Anime Pusulası

Yeni çıkan anime bölümleri, dünya çapında anime arama ve Türkçe altyazılı yasal izleme rehberi.

Bu depo uygulamanın güncelleme kaynağıdır:

| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Uygulamanın ekranı. Buradaki değişiklik, uygulama bir sonraki açılışta kendiliğinden gelir. |
| `version.json` | En son uygulama sürümü. `versionCode` artırılınca kullanıcıya bildirim gider. |
| `AnimePusulasi.apk` | En son derlenmiş uygulama. |

Anime verileri [AniList](https://anilist.co) üzerinden canlı gelir.
